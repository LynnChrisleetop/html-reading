# Thinking, Fast and Slow — Bilingual Reading Edition

This directory contains the current bilingual reading prototype for *Thinking, Fast and Slow*.

## Contents

- `快思慢想-双语阅读样版.html` — standalone browser reader
- `使用说明.md` — reading, notes, backup, and Eudic integration instructions
- `alignment.json` — English/Chinese alignment data
- `template.html` and build/check scripts — source and validation utilities

The current artifact is the first-chapter sample created so far, not a complete transcription of the whole book. Personal Eudic credentials are intentionally excluded from version control.

Open the HTML file directly in a current version of Edge or Chrome. Notes are stored in the browser's local IndexedDB; use the reader's backup function before moving the files or changing browsers.
