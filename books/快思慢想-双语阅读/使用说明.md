# 慢读：第一章双语样版

用 Edge 或 Chrome 打开「快思慢想-双语阅读样版.html」。无需联网，无需安装依赖。原始 EPUB 不会被修改。

本版只包含第一章，共 11 个经内容边界核对的阅读块。先读英文，点击「查看本节中文」展开洪兰译本。每次切换阅读块都会隐藏中文。插图直接嵌入文件。

## 笔记

- 右侧分别记录读英文时的理解、看译文后的修正。
- 在文本框内 Ctrl+V 粘贴图片，或用「添加笔记图片」。单图上限 8 MB。
- 选择英文或中文原文，可高亮或摘录并批注。
- 标记已读、待复习，阅读位置与字号自动保存。

## 保存和备份

自动保存使用当前浏览器的 IndexedDB，不写入 EPUB 或 HTML。更换浏览器、清除网站数据、移动 HTML 文件或改用本地服务器打开，可能看到不同的笔记库。隐私窗口不适合长期保存。

「备份全部」下载含图片的 JSON；换设备后用「恢复备份」恢复。恢复前会提示并自动下载当前状态的备份。建议每次阅读结束后导出一次。

「导出笔记」下载独立 HTML，含文字摘录、批注和图片，适合归档及阅读，但不能代替可恢复的 JSON。

## 范围

本版没有全书、跨设备自动同步、手写或自动词典。阅读块标题由阅读器添加；正文和译文来自提供的 EPUB。英文脚注引用用虚线提示，悬停可查看说明。

如果本机浏览器不允许本地文件使用 IndexedDB，界面会明确提示保存失败；此时可导出备份，不要依赖自动保存。

## 欧路查词与独立生词本

1. 如果旧 HTML 页面已有笔记，先点「备份全部」。
2. 双击本目录的 `start-eudic.cmd`，将启动仅本机可访问的连接程序，并打开 `http://127.0.0.1:18746`。程序窗口需保持运行；关闭即断开。
3. 在新页面「恢复备份」，迁移旧页面笔记。之后固定使用这个地址，避免两个笔记库分开更新。
4. 点顶部「欧路生词本」，从 https://my.eudic.net/OpenAPI/Doc_Index 登录获取完整个人授权信息，粘贴到密码框，点击连接。
5. 选择已有生词本，或新建「快思慢想 · 阅读生词」。同名时复用，遇到多个同名生词本则要求选择。
6. 选中正文英文 → 「欧路查词并收藏」 → 可修改词形 → 点击确认按钮。欧路释义另开网页，同时向专用生词本提交该单词。没有点击这个查词按钮的高亮不会同步。

API 授权使用 Windows DPAPI 为当前登录用户加密，保存在本目录 `.eudic-auth.bin`，不写进 HTML、笔记备份或日志。程序重启后自动加载授权并校验生词本。「断开账号」会清除保存的凭证。不要把授权信息放入共享文件。个人授权入口是 https://my.eudic.net/OpenAPI/Authorization 。

本版只发送所查的单词或短语，不发送正文、笔记、图片。欧路收藏需要联网；离线阅读和本地笔记仍可用。失败时显示未确认成功，恢复网络后可以重试。官方添加接口会忽略重复单词。

本工具不提供全词典 API 查询；「查词」是打开欧路网页的释义页，「收藏」通过官方生词本 API 完成。只使用列出、新建、添加接口。

## 查词自动高亮

点击确认「欧路查词并收藏」后，所查单词在正文中显示浅绿色，同一单词在其他阅读块再次出现时也会标出。忽略大小写、按完整单词匹配；不会把 he 标到 the 里面。若将所选 impressions 改成 impression 查询，两种词形都会记录，不自动推断其他词形。

手动高亮仍为黄色；重叠时保留黄色并加绿色下划线。查词记录随笔记自动保存并包含在「备份全部」中。旧版备份也能导入。

绿色表示已发起查词，不表示欧路收藏已成功。此前版本未记录的查词不会自动补回；更新后首次查询会开始记录。
